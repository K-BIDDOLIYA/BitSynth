# BitSynth 🎹

A tiny browser-based synthesizer built with HTML, CSS, and JavaScript.

### Features
- Play notes using your keyboard.
- Click piano keys to play sounds.
- Change octaves using Shift and Ctrl + Shift.
- Adjust volume.
- Play multiple notes together.

### Built With
- HTML
- CSS
- JavaScript
- Web Audio API

### Run
Open `index.html` in your browser and start playing!

Made for the Shrink project.
